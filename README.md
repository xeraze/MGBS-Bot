# MGBS Task Bot

Discord-бот для публикации задач, откликов участников и проверки выполненной работы.

## Возможности

- **Панель заданий** (`/panel`) — публикует сообщение с кнопкой "Задания". Нажатие открывает эфемеральный браузер: один эмбед - одно задание:
  - **Навигация** — выпадающее меню со слайдинговыми номерами страниц: `Назад · 1 2 3 4 5 · Далее`.
  - **Взять задание** — кнопка на странице задания; серая, если нет подходящей роли или заявка уже отправлена.
- **AFK-напоминания** — если участник ничего не писал на сервере, не был в голосовом канале дольше `AFK_HOURS` (по умолчанию 24 ч), а для его ролей есть открытые задания, бот пингует его в канале `AFK_PING_CHANNEL_ID` (по умолчанию `1562480044713181237`, с упоминанием ролей) и отправляет то же самое в ЛС. Повторный пинг одного участника по одному заданию — не чаще `AFK_REMINDER_COOLDOWN_HOURS`.
- **Комнаты заданий** — для каждого задания создаётся категория с каналами `info`, `general`, `voice`; права выдаются только участникам и лидерам направления.
- **Оценка и повышение** — после проверки работы лидер ставит оценки 1–10; бот автоматически повышает участников по иерархии ролей (билдеры, моделлеры, скриптеры).

```

|── __main__.py
|── bootstrap.py       логи, блокировка экземпляра, создание бота
|── config.py          ID каналов и ролей, настройки AFK
|── database.py        SQLite-хранилище
|── utils.py           общие помощники (логи, роли, эмбеды приветствия)
|── services.py        отправка заявки на задание
|── bot.py             комнаты заданий, права, повышения
|── banner.png
|── ui/
|   |── embeds.py      эмбеды панели и страниц заданий
|   |── panel.py       панель, браузер заданий (просмотр + выбор)

    |── panel.py       /panel, регистрация панели на старте

```

## Запуск на хостинге

1. Добавьте содержимое этой папки в отдельный Git-репозиторий.
2. Установите переменную окружения `DISCORD_TOKEN` в настройках хостинга. Не добавляйте токен в Git.
3. Команда запуска: `python -m mgbs_bot`.
4. Если хостинг использует Dockerfile, он уже настроен на эту команду.
5. Подключите постоянный диск к `/app/data` и задайте `DATA_DIR=/app/data`, чтобы база задач сохранялась после перезапуска.
6. Для быстрой синхронизации команд с одним сервером задайте `DISCORD_TEST_GUILD_ID`. Без неё команды синхронизируются глобально.

`TASK_BOT_DATABASE` можно задать как полный путь к файлу SQLite. Эта переменная имеет приоритет над `DATA_DIR`.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_TOKEN` | — | Токен бота (обязательно). |
| `DISCORD_TEST_GUILD_ID` | — | ID сервера для быстрой синхронизации команд. |
| `DATA_DIR` | `./data` | Каталог для базы и логов. |
| `TASK_BOT_DATABASE` | `<DATA_DIR>/tasks.sqlite3` | Полный путь к SQLite-файлу. |
| `AFK_PING_CHANNEL_ID` | `1562480044713181237` | Канал для AFK-пингов. `0` — только ЛС. |
| `AFK_HOURS` | `24` | Часы без активности до считания участника AFK. |
| `AFK_SCAN_INTERVAL_MINUTES` | `15` | Период сканирования, в минутах. |
| `AFK_REMINDER_COOLDOWN_HOURS` | `12` | Минимальный интервал повторного пинга участника по заданию. |
| `DISCORD_DEBUG` | `0` | `1` — включить подробный вывод синхронизации команд. |

## Секреты

`.env` и база данных исключены из Git. Для локального запуска используйте `.env.example` как шаблон. Если токен уже отправлялся в чат или публиковался, сбросьте его в Discord Developer Portal и обновите переменную на хостинге.
